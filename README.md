# Network Traffic Analysis Lab

## Overview

Built a controlled network security lab using Kali Linux,
Metasploitable 2 and Wireshark.

The objective was to capture and analyze common network
protocols and understand how network communication appears
at the packet level.

## Lab Environment

- Kali Linux
- Metasploitable 2
- VirtualBox
- Wireshark

## Network Protocols Analyzed

- DHCP
- DNS
- TCP
- HTTP
- SSH
- ICMP
- ARP
